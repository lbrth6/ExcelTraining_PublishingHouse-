# Module Excel – Master Édition

Supports du module Excel du master Édition (Faculté des lettres, Université de Strasbourg), publiés avec GitHub Pages.

Fil rouge : les **Éditions de l’Ill**, une maison d’édition strasbourgeoise fictive (40 titres, 6 genres, 4 canaux de vente).

## Contenu

- `index.html` : accueil
- `partie-1.html` : partie I (données, calculs, recherches) et mini-cas P1 à P9
- `partie-2.html` : partie II (tableaux, TCD, graphiques, vérification d’une IA) et mini-cas Q1 à Q3
- `mini-cas.html` : tous les exercices « À vous de jouer »
- `ressources.html` : fichiers à télécharger et raccourcis
- `fichiers/` : classeurs des mini-cas et supports en PDF
